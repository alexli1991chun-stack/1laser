# OneLaser Small Business Page

First-pass landing page concept for review: [Open the prototype](./index.html).

## Competitive page observations

The WeCreat small-business guide at https://wecreat.com/pages/make-money-buying-guide uses three useful patterns:
- Customer stories establish that real makers use the equipment to sell.
- Business/use-case groupings connect products to gifting, pets, events, and corporate orders.
- Product recommendations appear near those use cases, reducing the jump from inspiration to shopping.

## OneLaser adaptation

OneLaser's catalog supports a more production-oriented story: desktop precision (XRF), workshop versatility (Cobra), industrial throughput (Hydra), and specialist drinkware production (VertiGo). The page organizes around the buyer's business stage and order type, while using the brand's current support, warranty, shipping, and financing propositions.

## Review notes

- Static HTML concept only; it is not deployed to Shopify and does not alter the live theme.
- Product claims and destination URLs should be confirmed before launch.
- This draft uses no competitor images or videos. To complete the Shopify-ready version, select approved OneLaser-owned lifestyle imagery/video from the site and confirm usage rights and direct media URLs.
- Suggested next step: review copy, product mapping, imagery, preferred CTA, and target audience (new makers vs established production shops).
